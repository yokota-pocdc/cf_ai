# おこづかいC/Fノート — 企画書・機能仕様

## 1. プロダクト概要

### コンセプト
**「記録アプリ」ではなく「親子の金銭教育OS」**

AIチャットで子どものお小遣いを「投資・消費・浪費」に分類しながら記録し、
その行動文脈をもとに親向けの教育レポートを自動生成する、
子ども向け金銭教育プラットフォーム。

### ワンライン
> 「コンビニで350円使った」と話しかけるだけで、AIが一緒にお金の使い方を考えてくれるアプリ。

### ターゲットユーザー
- **メインユーザー**: 小学校高学年〜中学生（10〜15歳）
- **課金者**: その保護者

### 解決する課題

| 子どもの課題 | 親の課題 |
|---|---|
| 家計簿は面倒で続かない | 子どもが何にお金を使っているか分からない |
| お金の使い方を誰にも教わらない | お金の話をどう切り出していいか分からない |
| 「浪費した」と叱られるのが嫌 | 浪費を責めずに金銭感覚を育てたい |

## 2. 競合優位性

### 市場にないもの

調査の結果、以下の3要素を組み合わせたアプリは商用・OSSともに世界に存在しない。

| 要素 | 既存アプリ | 本アプリ |
|---|---|---|
| 記録方法 | フォーム手入力 | **AIチャットで自然に記録** |
| 分類体系 | 食費・交通費など一般カテゴリ | **投資・消費・浪費（教育的視点）** |
| 教育機能 | 分離（動画・クイズ） | **記録行為の中に教育が組み込まれている** |
| 行動分析 | 金額データのみ | **会話文脈（なぜ買ったか、どう感じたか）をAIが分析** |
| 親向け機能 | 支出一覧の閲覧 | **行動分析レポート + AI相談 + 声かけ例** |

### 既存プレイヤーとの比較

| アプリ | 特徴 | 本アプリとの違い |
|---|---|---|
| GoHenry / Greenlight | 子ども向けデビットカード + 管理 | AIなし、カード必須、日本非対応 |
| ハロまね（三井住友） | お小遣い帳 + 仮想銀行 | AIなし、教育機能は分離 |
| Cleo | AIチャット家計簿 | 大人向け、子ども機能なし |
| 家計簿FP | 投資/消費/浪費の3分類 | 大人向け、AIチャットなし |

## 3. 「投資・消費・浪費」フレームワーク

家計再生コンサルタント横山光昭氏が提唱する支出分類の考え方を、子どものお小遣いに適用。

| カテゴリ | 定義 | 子どもの具体例 | カラー |
|:---:|---|---|:---:|
| 🌱 投資 | 学び・成長・健康につながる支出 | 参考書、習い事、スポーツ用品、体のケア | グリーン |
| 🛒 消費 | 日常生活に必要で適切な支出 | 食事、交通費、文具、友人との交際 | パープル |
| 🎀 浪費 | 衝動的・計画外の支出 | ガチャ、衝動買い、不要な課金 | ピンク |

**設計思想**: 浪費を「悪」としない。「何%まで浪費OKか自分で決める」ことが教育の核。

## 8. ペルソナ・シミュレーション

### ペルソナ: 横田七海（よこた ななみ）
- 中学1年生（13歳）、女子、バスケ部
- にじさんじの壱百満天原サロメ推し
- 友達2〜3人とよく放課後にコンビニやカフェに行く
- 月のお小遣い: ¥5,000

### 6ヶ月の成長ストーリー

| 月 | 支出 | 🌱投資 | 🛒消費 | 🎀浪費 | ストーリー |
|---|---|---|---|---|---|
| **1月** | ¥3,020 | 0% | 40% | **60%** | 初月。ガチャに1000円、衝動買い。「絶対出ると思ってた」 |
| **2月** | ¥2,650 | 0% | 89% | **11%** | 反省→「1回だけ」と予算制導入。友チョコ手作り |
| **3月** | ¥2,930 | **53%** | 37% | 10% | 自発的に参考書購入。浪費予算を「お小遣いの10%」と設定 |
| **4月** | ¥2,200 | 27% | 59% | 14% | 「コンビニは週1回」マイルール定着。体のケアに投資 |
| **5月** | ¥3,350 | **45%** | 46% | 9% | 英検挑戦を自分で決意。「投資が投資を生む」と気づく |
| **6月** | ¥2,100 | 38% | 48% | 14% | **6ヶ月分のデータでお小遣いアップ交渉→¥6,000に** |

### 行動変化の追跡（他アプリにない差別化データ）

**ガチャへの態度の変化:**
```
1月: 「絶対出ると思ってた」→ 1000円浪費、後悔
2月: 「先月の反省があって…1回だけって決めてからやった」→ 300円に制限
3月: 「予算内だからOK」「お小遣いの10%くらい」→ 自分でルール設定
4月: 「ガチャは月1回300円って決めてる」→ ルール定着
5月: 「投資と浪費は別の予算だから」→ 予算を分けて管理
6月: 「浪費はゼロにしなくていい、管理できてればOK」→ 成熟した結論
```

## 9. ビジネスモデル案

### 課金設計

| プラン | 価格 | 内容 |
|---|---|---|
| **無料** | ¥0 | 記録＋チャット＋子ども向けダッシュボード |
| **ベーシック** | ¥480/月 | + 単月AIレポート + 記録の行動要約 |
| **プレミアム** | ¥980/月 | + 成長トレンドレポート + AI相談チャット + 親子会話テンプレート |

**設計思想**: 子どもは無料で使い続けてデータが溜まる → 親が「このデータを分析してほしい」と感じて課金する

### 親が課金する5つの理由

1. **親の手間が減る** — お金の話を切り出すきっかけをAIが作ってくれる
2. **子どもが変わるのが見える** — 浪費率60%→10%の数字、行動の変化
3. **家庭内の会話がラクになる** — 「データを見たけど、投資増えてるね」と褒めるだけでいい
4. **教育効果が見える** — 行動文脈付きの月次レポートで「考え方の成長」が分かる
5. **継続しないと損** — データが溜まるほど成長レポートの価値が上がる
